# `@workspace/landing`

BSL marketing landing for the morden-escpos print-queue SaaS.

Presents self-hosted, Personal, Business, and reseller-contact paths, and states
license expectations honestly: SaaS paths are **BUSL-1.1**, drivers remain
**MIT**.

## Commands

```bash
pnpm --filter @workspace/landing dev
pnpm --filter @workspace/landing typecheck
pnpm --filter @workspace/landing build
```

Dev server defaults to port `43129`.
