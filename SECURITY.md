# Security Policy

## Supported versions

Security fixes are prioritized for the latest published release of
`morden-node-escpos` on npm and for the `main` branch of this repository.

Older major versions may receive fixes at maintainer discretion.

## Reporting a vulnerability

**Do not** open a public GitHub issue for security vulnerabilities.

Prefer one of these private channels:

1. [GitHub private vulnerability reporting](https://github.com/gylove1994/morden-escpos/security/advisories/new) (recommended when enabled)
2. Email **gylove1994@acgsteps.com** with subject `[SECURITY] morden-escpos`

Please include:

- Affected package / path (e.g. `packages/morden-node-escpos`, browser adapters)
- Description of the issue and impact
- Steps to reproduce or a proof of concept
- Known affected versions / commits, if available

## What to expect

- We aim to acknowledge reports within **7 days**.
- We will keep you informed of triage progress and the planned fix timeline.
- Please do not disclose the issue publicly until a fix is released, or we agree on a disclosure date.
- Credit will be given in release notes if you want to be named.

## Scope notes

This monorepo includes MIT drivers and BSL SaaS apps. Reports are welcome for any path. License boundaries do not reduce our interest in fixing security issues; they only affect how fixes may be published.
