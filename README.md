# Modern Node ESC/POS Monorepo

基于 pnpm workspace 和 Turborepo 管理的 Modern Node ESC/POS 项目。

## 工作区

- [`packages/morden-node-escpos`](packages/morden-node-escpos)：可发布的 Node.js ESC/POS 打印机驱动

## 开发

```bash
pnpm install
pnpm build
pnpm test
pnpm lint
pnpm typecheck
```

库的安装方式、API 与示例请参阅
[`packages/morden-node-escpos/README.md`](packages/morden-node-escpos/README.md)。
